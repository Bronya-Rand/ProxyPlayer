# ProxyPlayer

ProxyPlayer is a simple plugin for XIV that lets use control what's playing on your computer using media controls in-game.

## Features
- Control any player on a browser, UWP app, or any player that supports Windows' SMTP (Standard Media Transport Protocol)
  - Play/Pause
  - Next/Previous
  - Shuffle/Repeat (on some players)
  - Current Progress/Duration (on some players)
  - Metadata
- Compact/Portrait UI
