# ProxyPlayer

ProxyPlayer is a simple plugin for XIV that lets use control what's playing on your computer using media controls in-game. (Both Windows and Linux\* are supported).
  
> \* - With modern Wine/Proton builds available on XIVLauncher and XIVLauncher-RB (GE-Proton 11-4+). Older builds of Wine/Proton or those without `AF_UNIX` support will not be able to use this plugin.

## Features
- Control any player on a browser, UWP app (Windows), or any player that supports either Windows' SMTP (Standard Media Transport Protocol) or MPRIS (Linux).
  - Play/Pause
  - Next/Previous
  - Shuffle/Repeat (on some players)
  - Current Progress/Duration (on some players)
  - Metadata
- Compact/Portrait UI
